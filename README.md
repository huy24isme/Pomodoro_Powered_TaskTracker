# Pomodoro Task Tracker

## Structure

- frontend: Next.js App Router, TypeScript, ESLint, TailwindCSS
- backend: Node.js, Express, CORS, dotenv

## Main scripts

- `npm run dev` from root: run frontend and backend together
- `npm run build` from root: build frontend
- `npm run lint` from root: lint frontend
- `npm run dev --prefix backend`: run backend only
- `npm run dev --prefix frontend`: run frontend only
